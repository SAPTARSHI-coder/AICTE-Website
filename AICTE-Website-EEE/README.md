# AICTE VAANI Sponsored National Workshop — Department of EEE

An interactive, responsive web portal for the AICTE-VAANI Sponsored Three-Day National Workshop on **"Recent Trends in Semiconductor Devices, VLSI Design, and Microelectronics"** organized by the Department of Electrical & Electronic Engineering (EEE), Adamas University.

---

## ⚡ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Library:** [React 18](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Type Safety:** [TypeScript](https://www.typescriptlang.org/)

---

## ✨ Features

- **3D Constellation Background:** Interactive particle canvas reacting to cursor and touch dynamics.
- **Bilingual Interface:** Full-page Bengali and English language localization switcher.
- **Workshop Highlights:** Schedules, keynote speakers, organizing committee, and technical tracks.
- **Registration Workflows:** Step-by-step registration instructions via the AICTE ATAL portal.
- **Theme Support:** Polished Dark and Light mode themes.

---

## 🚀 Getting Started

### Prerequisites

- Node.js >= 18.x
- npm >= 9.x

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm run start
```

### Linting

```bash
npm run lint
```
