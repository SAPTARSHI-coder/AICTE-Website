# AICTE-VAANI Sponsored Three Days Workshop — Department of CSE

Official web portal for the AICTE-VAANI Sponsored Three-Day National Workshop organized by the Department of Computer Science & Engineering (CSE), Adamas University.

---

## 💻 Tech Stack

- **HTML5 & CSS3**
- **JavaScript (Vanilla ES6)**
- **Tailwind CSS (CDN)**
- **Font Awesome Icons**

---

## ✨ Features

- **Workshop Overview:** Objectives, target audience, and eligibility details.
- **Language Switcher:** English and Bengali translation toggle.
- **Program Schedule:** Session timeline and technical talks.
- **Speaker & Committee Showcase:** Faculty coordinators, patrons, and keynote speakers.
- **Document Downloads:** Downloadable workshop brochure and schedule PDFs.

---

## 🚀 Running the Project

Since this is a static website, you can view it directly:

1. Open `index.html` in any web browser.
2. Or serve it using a local static web server:
   ```bash
   npx serve .
   ```
